# 06 · 国服游戏与直播

## 游戏：能登录，但延迟高

国服游戏多数不拦境外 IP，问题是延迟。人在欧美，到国内服务器物理距离决定了基础延迟在 150 毫秒以上，再加上跨境链路的抖动和丢包，表现为卡顿、掉线。

"加速"做的事是：把你的流量走一条到国内更优的线路，减少绕路和丢包。它把抖动、丢包的连接变成稳定的连接，对多数游戏这就是能玩和不能玩的区别。

## 怎么选入口

地区选的是流量落地的国家：国服游戏选**中国区**，出去的就是国内 IP。不要选德国、法国这类经第三方中继的地区，它们不走 UDP，游戏基本连不上。多测几个，用游戏内延迟显示做判断。

## 协议选择

游戏对丢包敏感，优先选走 UDP 的协议，并避开不支持 UDP 的中继地区。TCP 类协议在丢包时会重传，延迟跳得厉害。

## 直播

抖音、快手、斗鱼、虎牙对境外 IP 的限制不一，多数能看但清晰度受限。换中国 IP 后可以解锁完整清晰度选项。直播是持续高码率流量，选带宽充足的入口。

## 实名

国服游戏需要实名认证，这是账号层面的要求，和 IP 无关，换 IP 解决不了。
