# 07 · 该不该上路由器，四个型号怎么挑

> 网站版（更长、含繁体与英文）：https://7d24hrs.com/zh-CN/guides/router?utm_source=github&utm_content=router-07

路由器方案解决的是"设备太多、有些装不了客户端"：线路在路由器上建一次，电视、游戏机、音箱、老人手机全部自动走，什么都不用装。需要的只是一台能刷固件的路由器和十分钟刷机。**个人、家庭、企业三档账号都能用路由器。**

## 该用与不该用

| 该用 | 不该用 |
|---|---|
| 家里有电视盒子、游戏机、Apple TV、音箱这类装不了客户端的设备 | 只有一台手机一台电脑、以出差为主——装客户端更轻 |
| 家庭成员多，不想逐台教 | 住宿舍、合租，网络不由你控制 |
| 需要 24 小时挂着的设备（NAS、摄像头回传） | 主路由是运营商锁定的光猫又不能接二级路由——用便携路由器折中 |
| 国内办公室或全家稳定出海，路由器上分流，设备无感 | |

## 刷固件还是买成品

两条路最后跑的是同一套固件，区别在谁来刷、出了问题谁负责。

- **自己刷**：已有 OpenWrt 支持的路由器（1000 多个型号），网站上在线编译，3～5 分钟后邮件收链接，照着 [02 · 自己刷固件](02-flash-firmware-yourself.md)一步步做（有视频）。适合动手能力强、想省一台机器钱的人。
- **买成品**：寄一台刷好固件的 GL.iNet，到手三步见 [01](01-plug-and-play-router.md)。适合不想折腾，或者给不懂技术的家人。

两条路固件都会自己更新组件，不用重新刷机；线路地址变了也不用改配置。

### 按场景速查

- 一个人出差住酒店，预算有限 → GL-MT300N-V2
- 租房、小家庭、电视和盒子要看国内或国外的视频 → GL-MT3000
- 在家用，偶尔出差也想带着 → GL-MT3000
- 大房子、设备多、宽带在千兆以上，或办公室多人共用 → GL-MT6000
- 没有宽带，或人经常在路上 → GL-XE3000
- 给不懂技术的父母装一台 → GL-MT3000 买成品，到手插电就能用

## 为什么我们首推 GL-MT3000

- **一台顶两种用法**：性能够当小家庭的主路由，体积又小到能随身带。四款里只有它两头都占。
- **规格不会很快过时**：Wi‑Fi 6 加 2.5G 网口，对多数家庭宽带都有余量。迷你款只有 2.4G 和百兆口，家里用会成为瓶颈。
- **价格划算**：$300 附赠 24 个月个人档服务；迷你款 $200 附赠 12 个月。把附赠的服务时长算进去，多花的 $100 换来的是高一档的硬件再加一年服务。
- **我们最熟悉它**：自己的测试机就是这一款，新固件先在它上面验证，[刷机视频教程](02-flash-firmware-yourself.md)演示的也是它。遇到问题时，我们手边有同一台机器可以对照。

什么时候不选它：房子大、设备多或宽带在千兆以上，直接上 GL-MT6000；没有固定宽带，选 GL-XE3000；只是出差时一个人用、想尽量省钱，GL-MT300N-V2 就够。

## 上手后最常见的三个问题

- **Wi‑Fi 信号弱、只有 20 dBm**：固件按所在国家法规自动设无线功率，要等路由器联网一次才切到你所在国家的档位，刚刷完先插网线。
- **国内网站变慢**（人在国内）：分流没开，全走了线路。在分流设置里选「正向分流」，国内 IP 直连、其余走线路。
- **人在海外想看国内内容**：选「反向分流」。反向分流就是把方向倒过来——只有中国大陆的 IP 走回国线路，其余网站照常走当地宽带直连。国内的视频、音乐和 App 看到的是国内地址，当地的网站和流媒体不绕路。固件会按路由器所在地自动选好方向，一般不用手动改。见 [03 · 路由器分流](03-router-split-routing.md)。
- **某台设备不走线路**：那台设备自己设了私人 DNS（安卓"私人 DNS"、浏览器安全 DNS），关掉。

## 常见问题

**路由器算一台设备吗？** 占账号一个名额（按档位个人 2 台、家庭 4 台、企业 8 台同时在线），它后面的设备不再单独计数。

**能回国看视频吗？** 能，线路选中国区。路由器把整个局域网接进线路，设备的 IPv6 和 DNS 都到不了外面，比手机单独连更少出"版权限制"。见 [06](06-unlock-chinese-video-with-router.md)。

**固件有没有后门？** 基于 OpenWrt 编译，只多了连线路的组件和分流规则；线路只记录连接时长和流量总量用于计费，不记录访问内容。
